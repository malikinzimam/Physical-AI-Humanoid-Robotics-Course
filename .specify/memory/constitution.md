# Robotic Book Constitution

## Core Principles

### I. AI/Spec-Driven Book Creation
Write a book using Docusaurus and deploy it to GitHub Pages. You will use Spec-Kit Plus and Claude Code to write the book.

### II. Integrated RAG Chatbot Development
Build and embed a Retrieval-Augmented Generation (RAG) chatbot within the published book. This chatbot, utilizing the OpenAI Agents/ChatKit SDKs, FastAPI, Neon Serverless Postgres database, and Qdrant Cloud Free Tier, must be able to answer user questions about the book's content, including answering questions based only on text selected by the user.

### III. Reusable Intelligence
Participants can earn up to 50 extra bonus points by creating and using reusable intelligence via Claude Code Subagents and Agent Skills in the book project.

### IV. User Authentication
Participants can receive up to 50 extra bonus points if they also implement Signup and Signin using https://www.better-auth.com/.

### V. Content Personalization
Participants can receive up to 50 extra bonus points if the logged user can personalise the content in the chapters by pressing a button at the start of each chapter.

### VI. Content Translation
Participants can receive up to 50 extra bonus points if the logged user can translate the content in Urdu in the chapters by pressing a button at the start of each chapter.

## Additional Constraints
The project must be completed using Claude Code and Spec-Kit Plus. The final submission must include a public GitHub repo link, a published book link, and a demo video under 90 seconds.

## Development Workflow
We will follow a Spec-Driven Development (SDD) approach, which includes creating a spec, a plan, and then implementing the tasks. All pull requests and reviews must verify compliance with these principles.

## Governance
This Constitution supersedes all other practices. Amendments require documentation, approval, and a migration plan.
